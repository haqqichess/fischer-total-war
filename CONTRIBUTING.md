
# Contributing to Fischer Total War

Thank you for taking an interest in Fischer Total War.

FTW is an experimental chess variant, and thoughtful feedback is an important part of its development. You do not need to be a chess expert or a developer to contribute. Clear observations from actual games are especially valuable.

## What You Can Contribute

There are several ways to help:

- Report unclear or inconsistent rules.
- Share results from playtesting.
- Suggest improvements to existing mechanics.
- Identify unusual positions or edge cases.
- Improve the documentation.
- Share ideas for tools or implementations that support FTW.

## Reporting a Problem

Before reporting a rules issue, check the current version of the documentation.

A useful report should include as much of the following information as possible:

1. The FTW rules version you used.
2. The starting Chess960 position or its recorded FEN.
3. The move sequence leading to the situation.
4. The rule or section involved.
5. What you expected to happen.
6. What actually happened.
7. Why you believe the situation needs clarification or a change.

Screenshots or position diagrams are welcome when they help explain the problem.

## Proposing a Rule Change

Rule changes should be presented as proposals, not assumed to be accepted.

When suggesting a change, explain:
- The problem you are trying to solve.
- How the proposed rule would work.
- Which existing rules it might affect.
- At least one example position or game situation.
- Any possible disadvantages or unintended consequences.

A change that makes sense in one position may create problems in another. Consider its wider impact before proposing it.

## Documentation Contributions

Pull requests that improve clarity, correct mistakes, or add useful examples are welcome.

Please keep the following principles in mind:

- Use clear and consistent language.
- Keep terminology consistent with `docs/TERMINOLOGY.md`.
- Do not silently introduce new game rules.
- Identify proposed rule changes clearly.
- Update the changelog when an accepted change affects the rules.

The rules should remain easy to understand for players who are discovering FTW for the first time.

## Community Guidelines

Keep discussions respectful and focused on the ideas being discussed.

Different opinions are expected. Criticism is welcome when it is specific and constructive. Personal attacks, harassment, and deliberate disruption are not.

A suggestion does not need to be accepted to be worth discussing.
